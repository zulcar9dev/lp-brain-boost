## 8. Desain - nuansa Money tapi tetap kalem (anti AI slop)

Kamu pilih Nuansa Money. Rekomendasi saya:

- Base tetap navy `#2E2B5E` biar nyambung sama Tidur (hemat CSS `_shared/`), kartu ganti ke krem hangat `#FFF8E6` + aksen emas `#C9A227`. CTA tetap dikunci 1 warna amber `#FFB020` (kontras AA di navy). Jangan campur hijau / biru / ungu neon di section lain.
- Radius dikunci: kartu 16px, tombol pill penuh, input 8px. Jangan campur.
- Font: Plus Jakarta Sans self-host 500/700 saja. Larang Inter default & serif display. H1 28-34px mobile, 40-52px desktop, max 2 baris.
- Layout rhythm variasi: split hero -> problem list -> full-width quote -> grid outcome -> accordion FAQ. Larang zigzag image-teks 3x berturut-turut, larang 3 kartu equal + mesh gradient + glassmorphism semua kartu.
- Eyebrow max 1 per 3 section. Hero pakai `BrainBoost Money Magnet`, section lain langsung headline.
- Ikon 1 family phosphor (coin, moon, headphones). Larang emoji di UI.
- Motion cuma transform/opacity 0.6s ease `[0.16,1,0.3,1]`, reveal via IntersectionObserver. Mati total di `prefers-reduced-motion`.
- A11y: `min-h-[100dvh]` bukan `h-screen`, Grid bukan flex-math, CTA 1 baris.

## 9. Tech - ikut template Tidur

- Frontend: statis single-file `index.html + styles.css native + app.js vanilla <50KB + config.js`. Total <400KB. Alasan: LCP <2.5s HP Android 4G, lolos review Meta.
- Ditolak untuk v1: Next.js/React (overkill 80-150KB), WordPress/Elementor (berat, CLS jebol), page-builder gratisan (domain curiga).
- Backend: tidak ada. Checkout 100% di Mahir Digital.
- File v1: `/site/money-magnet/index.html + /assets/*.webp + PRD-MONEY-MAGNET.md mini` + reuse `/site/_shared/styles.css, app.js, config.js, privacy.html`
- Config: tambah mapping `money-magnet: CHECKOUT_URL i=11, PRICE 298000, PIXEL_ID_MAGNET, content_name money-magnet`. Tidur tetap pakai PIXEL_ID_TIDUR sendiri. Jangan hardcode di HTML. `app.js` pilih Pixel per `data-product`.
- Events: PageView -> ViewContent (hero observer, value 298000 IDR) -> AffiliateClick + InitiateCheckout (semua CTA bawa utm + data-cta + event_id).
- UTM wajib: `utm_campaign=magnet_{angle}` contoh `magnet_filter_cold1`. JS teruskan ke checkout.
- Hosting: Cloudflare Pages, publish dir `site`, domain sendiri + HTTPS + verifikasi BM + `/privacy.html` + cookie banner mini.
- Budget: PageSpeed mobile >=85, LCP <2.5s, INP <200ms, CLS <0.1.
